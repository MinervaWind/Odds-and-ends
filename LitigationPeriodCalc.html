计算规则说明
  1. 起算：文书发出日（A）当日不计入，自次日起算（《民法典》第 201 条）。
  2. 主口径届满日：按日 = A + N 天；按月 = A 的对应日，无对应日取当月最后一日。
  3. 宽松口径届满日：从次日起完整数 N 天，即主口径名义届满日再加 1 天（A + N + 1），单独顺延。
  4. 顺延：届满日为周六、周日或法定节假日时，顺延至其后第一个工作日，可连锁顺延；调休上班的周六日视为工作日。
  5. 判定：B ≤ C 未超期；B = C 提示人工复核；主口径已超期但未超过宽松口径时提示可能超期、人工复核；超过宽松口径为超期；B < A 提示日期可能有误。

本工具结果仅供参考，最终以法律规定及案件实际情况为准。
