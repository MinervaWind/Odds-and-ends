# Odds-and-ends
自制HTML小工具合集。内容不定，更新不定，上传主要是为了自己和亲友使用方便。
所有工具均为单个 HTML 文件，纯前端运行，不上传任何数据，下载到本地双击即可使用；也可以直接点下面的标题在线打开。

## 内容介绍

### [Todo·随手待办](https://minervawind.github.io/Odds-and-ends/todo.html)
一个单文件的待办工具，在浏览器上运行。如果需要跨设备同步，可以考虑将数据存进**GitHub私有仓库**，保证隐私。
#### 功能
- **待办**
可自定义待办分类，可同时筛选多个待办类别，可自由添加备注（默认不显示），可自定义待办重复。重复待办分两种：
  必做：当天没做会标成实心灰点。
  有就做：当天没做留空心，不算漏做。
- **打卡**
每条重复待办后面跟一排圆点，代表最近七天；实心亮色＝做了，实心暗色＝该做没做，空心＝那天未轮到做。记录本身最多留 400 天，够覆盖一整段实习或一学期。
- **更适合选恐的随机**
从指定范围里随机挑一条出来。范围可以是全部，也可以是某个分类。适合“知道该干活但不知道从哪开始”。
- **日夜模式**　首次跟随系统，之后记住你的选择。
- **备份**　导出 JSON 或纯文本打卡记录，可下载可复制。导入支持**合并**（按条目比对，选择新版本，打卡记录取并集）和**覆盖**。
#### 直接使用
打开网址就能用，什么都不用配。数据存在浏览器本地。手机上建议**添加到主屏幕**。
代价是换设备就看不到，清浏览器缓存就没了。所以如果你打算长期用，建议接上同步。
#### 接同步（可选）
**1. 建一个私有仓库**
名字随便，比如 `todo-data`。**务必勾 Private。** 里面不用放任何东西，数据文件会自动创建。
**2. 生成 token**
GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
- Repository access：**Only select repositories**，只选上一步那个仓库
- Permissions → Repository permissions → **Contents: Read and write**（只给这一项，Metadata 是强制带的，去不掉）
- Expiration：别选最长，三个月左右比较合适
生成后那串 `github_pat_...` **只显示一次**，先存下来。
**3. 填进工具**
页面底部「同步设置」，填 owner（你的用户名）、repo（仓库名，区分大小写）、token。先点**测试连接**，再点**保存并同步**。
其他设备重复第 3 步就行，token 是同一串。
接上之后：改动攒 5 秒自动提交，切到后台或关页面时立刻提交。两台设备同时改会自动合并，不是简单覆盖。
#### 风险说明
1. 为什么你可以在这个工具里使用token？
**这个页面没有后端。** 它是一个静态 HTML 文件，没有服务器，没有数据库，没有任何属于我的地方可以接收你的数据。
**token 只存在你浏览器的 localStorage 里**，不会出现在网址、不会被发往 `api.github.com` 以外的任何地方。
**代码就在这个仓库里**，一个文件，可以自己翻。搜 `fetch(` 能看到全部的网络请求去向。
**不放心可以 fork 一份**挂在自己的 GitHub Pages 上，用你自己的地址。这是最彻底的办法，我也推荐。
另外，上面那套 token 配置本身就是最小权限：它只能读写你指定的那**一个**私有仓库里的文件，碰不到你其他任何仓库，也做不了创建、删除、改设置之类的事。就算泄露，损失范围是你自己的待办清单，并且到期会自动失效。
2. 其他已知限制
**没有定时提醒。** 网页做不到可靠的后台通知，移动端尤其如此。这是平台限制，不是没做。需要到点被提醒的事，交给系统自带的提醒事项或闹钟。
**每次同步是一次 commit。** 已经做了 5 秒防抖，但长期使用下来那个数据仓库的提交历史会很长。另外 **git 历史是永久的**——删掉的备注内容在历史里仍然存在。
**打卡记录上限 400 天**，超过的会被丢弃。需要长期留存的话定期导出一份。
**私有仓库不要误设成公开。** 数据文件是明文 JSON，公开了就是谁都能看。

### [anke-dice](https://minervawind.github.io/Odds-and-ends/anke-dice.html)
骰点工具，可能较为适合日常骰点和安科，也可以用作临时跑团用。四种模式：

- **自由骰**：支持多种表达式，输入时会提供注释。可自定义常用数值补正，点击即可接到表达式末尾，名称同时写进备注。
- **判定**：内置 COC7 分级与单阈值，也可自定义分级表。判定骰、每级名称与阈值都能改，阈值支持 `值/2`、`floor(值/5)` 这类算式，因此 d100、2d6、d20 系规则都能跑。附 COC7 式 / 固定区间式 / 2d6 日系式 / DC 式四种预设。
- **角色**：记录技能数值，点一下直接套用当前判定方案检定，结果连角色名一起写进日志。
- **随机表**：分条填写权重与内容，实时显示每条的中签率，抽取结果带序号。

默认使用 `crypto.getRandomValues` 抽取，不可复现，适合自用。另有种子模式：该模式下骰点结果由 [种子 + 序号 + 表达式] 唯一决定，把这三项连同结果一起贴出，任何人输入同样的三项都会得到同一个数——用于需要向读者取信的场合，避免作者反复重 roll的嫌疑。

骰点日志只增不减，可一键复制成适合贴楼的纯文本。所有数据（角色、随机表、常用补正、分级表）只存在浏览器本地，清缓存即丢失，页脚的「数据备份」可导出导入，请自行留档。

（骰点逻辑是通用的，拿来跑团也行。但如果需要的是群内指令、牌堆、角色卡托管这些，建议直接用骰娘。）

### [chat-formatter](https://minervawind.github.io/Odds-and-ends/chat-formatter.html)
能够初步梳理 QQ 聊天记录（兼容电脑端和手机端的复制格式），一键识别发言人、修改用户名、删除时间戳、合并短句并对格式进行排版，成品支持复制为 Markdown 格式和纯文本格式。（初衷只是为了方便整理跟亲友的口嗑，如果需要更细腻的编辑功能，建议参考使用市面上的跑团 log 着色器。）

### [inkcard](https://minervawind.github.io/Odds-and-ends/inkcard.html)
文字转图片生成器。支持三种输出模式：一张长图、自由分页（正文内写 === 手动断页，并可设置单张高度上限）、小红书 3:4 竖版分页（按段落自动分页，一次打包下载 ZIP）。附标点规范、去除 Markdown 语法、中英加空格等文本清理工具，支持首行缩进、署名水印、字数与阅读时长显示，色板可在界面内增删命名。（含有作者喜好的个性化配色方案，不推荐他人使用。）

### [tarot](https://minervawind.github.io/Odds-and-ends/tarot.html)
塔罗抽牌小工具。使用 `crypto.getRandomValues`（浏览器提供的加密级随机数），而不是普通的 `Math.random()`，抽牌和正逆位判定都基于此。每次抽牌会真正洗一副 78 张的完整牌堆，抽出的牌从牌堆中移除，直到重新洗牌。纯属娱乐，帮助梳理思路和心情用，不构成任何形式的预测或建议。
牌组为标准 78 张塔罗牌：22 张大阿卡纳 + 56 张小阿卡纳（权杖 / 圣杯 / 宝剑 / 星币，各 14 张）。
