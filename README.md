# Odds-and-ends
自制HTML小工具合集。内容不定，更新不定，上传主要是为了自己和亲友使用方便。

## 内容介绍
### chat-formatter
能够初步梳理 QQ 聊天记录（兼容电脑端和手机端的复制格式），一键识别发言人、修改用户名、删除时间戳、合并短句并对格式进行排版，成品支持复制为 Markdown 格式和纯文本格式。（初衷只是为了方便整理跟亲友的口嗑，如果需要更细腻的编辑功能，建议参考使用市面上的跑团 log 着色器。）
### inkcard
文字转图片生成器。支持三种输出模式：一张长图、自由分页（正文内写 === 手动断页，并可设置单张高度上限）、小红书 3:4 竖版分页（按段落自动分页，一次打包下载 ZIP）。附标点规范、去除 Markdown 语法、中英加空格等文本清理工具，支持首行缩进、署名水印、字数与阅读时长显示，色板可在界面内增删命名。（含有作者喜好的个性化配色方案，不推荐他人使用。）
### tarot
# 塔罗抽牌工具
一个单文件、纯前端、可离线运行的塔罗抽牌小工具。使用 `crypto.getRandomValues`（浏览器提供的加密级随机数），而不是普通的 `Math.random()`，抽牌和正逆位判定都基于此。每次抽牌会真正洗一副 78 张的完整牌堆，抽出的牌从牌堆中移除，直到重新洗牌。纯属娱乐，帮助梳理思路和心情用，不构成任何形式的预测或建议。
牌组为标准 78 张塔罗牌：22 张大阿卡纳 + 56 张小阿卡纳（权杖 / 圣杯 / 宝剑 / 星币，各 14 张）。
